# /dev/fit 2026 (оптимизация алгоритмов управления лифтовой системой)

## 1. Описание задачи
В 11-этажном офисном здании эксплуатируется лифт с максимальной вместимостью **8 человек**. Система функционирует в условиях неравномерного пассажиропотока:
* **Утро:** массовый подъем работников с 1-го этажа на рабочие места.
* **Обед:** спуск в кафе на 1-й этаж или выход на улицу.
* **Вечер:** массовый спуск со всех этажей для ухода домой.
* **День:** межэтажные перемещения, прибытие и убытие людей.
* **Ночь:** единичные перемещения охранников и технического персонала.

**Цель:** разработать алгоритм управления лифтом (`my_way`), максимизирующий итоговый показатель эффективности (Счет).

---

## 2. Целевая функция и метрики
Эффективность алгоритма оценивается по формуле:

**Счет = (1000 × P) / (AWT + 3 × ART + 60 × (L / P))**

**Компоненты метрики:**
* **P** (количество перевезенных пассажиров) — целевой показатель, требуется максимизировать.
* **AWT** (среднее время ожидания, с) — среднее время ожидания лифта одним человеком.
* **ART** (среднее время поездки, с) — средняя длительность доставки пассажира к цели.
* **L** (общий пробег, этажей) — эквивалент энергопотребления, негативный показатель (требуется минимизировать).

*Примечание: метрики обновляются на основе завершенных поездок. Незавершенные поездки в конце симуляции принудительно завершаются и учитываются в итоговом результате.*

---

## 3. Параметры симуляции
В процессе локального тестирования параметры могут быть изменены, однако **на финальном прогоне они будут строго переопределены** организаторами:
* **NUM_DAYS:** `7` (длительность эксперимента в днях).
* **SEED:** единое для всех участников (зерно генератора трафика).
* **DENS:** `0.3` (плотность трафика).
* **SPEED_MULT:** `64` (множитель скорости симуляции).
* **START_TIME:** `0` (стартовое время симуляции в часах).

---

## 4. Физические ограничения и свойства системы
1. **Скорость:** 6 этажей в минуту (не зависит от загруженности).
2. **Время остановки:** 30 секунд на этаже (даже если высадка не производится). Оптимизация: минимизировать количество необоснованных остановок.
3. **Индексация:** нумерация этажей начинается с **1**. Индексация всех остальных сущностей (списки, массивы) начинается с **0**.
4. **Информированность:** лифт **не знает** текущего времени (алгоритм должен определять его косвенно, если это необходимо).

---

## 5. Конечный автомат состояний (State Machine)
Функция управления `my_way(...)` вызывается **исключительно** в состоянии `IDLE`.

* **`IDLE`** — лифт стоит на этаже и ждет команд.
* **`MOVING`** — лифт уезжает на целевой этаж (посадка и высадка на текущем этаже блокируются).
* **`DOORS_OPEN`** — происходит открытие дверей лифта. Активируется сразу после достижения целевого этажа. Спустя 30 секунд переходит в `IDLE`.

## 6. API лифта (Elevator API)

### 6.1. Методы получения информации (Read-only)
*Использование иных методов строго запрещено.*

* `elevator.get_current_floor() -> int` — текущий этаж лифта.
* `elevator.get_target_floor() -> int` — целевой этаж, к которому движется лифт.
* `elevator.get_passengers_count() -> int` — количество пассажиров внутри лифта.
* `elevator.get_capacity() -> int` — максимальная вместимость лифта.
* `elevator.get_building_floors() -> int` — количество этажей в здании.
* `elevator.get_passenger_destinations() -> List[int]` — список целей текущих пассажиров.
* `elevator.get_waiting_floors() -> List[int]` — список этажей, где есть ожидающие.
* `elevator.get_waiting_people(f: int = None) -> List[int]` — список целей у ожидающих на этаже `f` (если этаж не указан, то на текущем этаже).

### 6.2. Методы управления лифтом (Write)
*Управление доступно только в состоянии `IDLE`. Использование иных методов строго запрещено.*

* `elevator.go_to_and_stop(f: int)` 
  * Переводит лифт в `MOVING`.
  * Лифт поедет на указанный этаж `f` без остановок.
  * По прибытии перейдет в `DOORS_OPEN`.
  * *Ограничения:* не сработает, если лифт уже в `MOVING` или уже находится на целевом этаже.
* `elevator.unload_all()` 
  * Высадить тех, кто выходит на этом этаже.
* `elevator.board_first_passenger() -> bool` 
  * Посадить первого пассажира из очереди в лифт.
  * Удаляет человека из списка ожидающих на этаже.
  * Успешность посадки возвращается как логический флаг (для посадки всех доступных пассажиров метод следует вызывать в цикле до возврата `False`).

## 7. Инструкции по реализации

### 7.1. Подготовка окружения
1. Клонируйте репозиторий:
   `git clone https://github.com/EgorAdamovsky/dev-fit-2026`
2. Установите необходимые зависимости:
   `pip install -r requirements.txt`
3. Запустите демонстрационный скрипт:
   `python main.py`

### 7.2. Разработка алгоритма
Вся логика управления реализуется **только** в файле `dev.py`.

1. Установите значение переменной `TEAM` на название вашей команды.
2. Реализуйте свою логику в теле функции `my_way(elevator: Elevator)`.
   * *Важно:* сигнатуру функции изменять **запрещено**.
   * *Важно:* предоставленный в шаблоне код является лишь примером; ваше решение должно отличаться.
3. Для хранения состояния между вызовами `my_way()` допускается использование дополнительных переменных.

### 7.3. Строгие ограничения
* **Запрещено** вносить изменения в любые файлы проекта, кроме `dev.py`.
* **Запрещено** использовать методы API, не описанные в разделе 6.
* Изменения параметров симуляции в `dev.py` учитываются только при локальном тестировании.

## 8. Пример базового алгоритма
Минимальный рабочий, но неэффективный алгоритм приведен в `dev.py` и занимает 11 строк кода. Итоговый счет этого алгоритма составляет ~3500 очков. Оптимизация позволяет достичь ~4500 очков и выше.

```python
import random

def my_way(elevator: Elevator):
    # 1. Высаживаем всех, кому нужно на текущий этаж
    elevator.unload_all()
    
    # 2. Сажаем пассажиров с текущего этажа, пока есть место и очередь
    if elevator.get_waiting_people():
        while elevator.board_first_passenger():
            pass
            
    # 3. Выбираем следующую цель
    passes = elevator.get_passenger_destinations()
    waiting_floors = elevator.get_waiting_floors()
    
    if passes:
        # Если есть пассажиры, едем к цели одного из них (случайный выбор)
        target = passes[random.randint(0, len(passes) - 1)]
        elevator.go_to_and_stop(target)
    elif waiting_floors:
        # Если лифт пуст, едем забирать ожидающих (случайный выбор)
        target = waiting_floors[random.randint(0, len(waiting_floors) - 1)]
        elevator.go_to_and_stop(target)
